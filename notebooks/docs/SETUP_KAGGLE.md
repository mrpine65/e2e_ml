## Setting Up Your Kaggle Account

To use the **Kaggle API**, you first need to create a Kaggle account at [https://www.kaggle.com](https://www.kaggle.com). <img src="../images/kaggle1.png" alt="Kaggle signup page">

Next, navigate to the **Account** tab in your user profile:
[https://www.kaggle.com/ <username>/account](https://www.kaggle.com/<username>/account) <img src="../images/kaggle2.png" alt="Kaggle account settings">

Click **“Create API Token”**. This will download a file named `kaggle.json`, which contains your API credentials. <img src="../images/kaggle3.png" alt="Create API Token button">

Finally, place your **Kaggle API credentials** in the `credentials.yaml` file. These credentials will be used to authenticate and download datasets via the Kaggle API.
